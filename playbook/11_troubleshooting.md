# 11 つまずき・原因・次回の避け方

速度改修で起こり得る問題と切り分け方をまとめた。特定の案件の障害履歴ではない。

| 項目 | 問題・誤解 | 対処 |
| --- | --- | --- |
| 症状から即断 | 動画容量だけで「Wi-Fi問題の原因確定」と言う | URL・端末・操作・回線別に再現し、HTTPと描画を切り分ける |
| CSS圧縮と構造 | gzipで巨大セレクターの解析まで解消したと思う | 転送量と展開後のCSS処理を別課題にする |
| 試算値の混在 | 条件の異なる圧縮サイズを同一条件の実測として使う | 元ファイルSHA・圧縮方式・レベル・日時を付ける |
| キャッシュ逆転 | beforeが温まってafterが初回なのに比較する | 新規contextと同一contextでの再アクセスを定義する |
| 転送量の名前 | encodedBodySizeをそのアクセスでの転送量と表示する | HTML込みtransferSizeと本体サイズを分ける |
| 304とヒット | 304を通信なしに数える | 再検証要求とmemory/disk cacheを別に見る |
| 一括no-cache | 比較のため全資産のキャッシュを無効にする | 観測した基準版の配信を再現し、比較対象だけ変える |
| 観測コード混入 | guardや計測スクリプトの増減をサイト改善に含める | 同一観測版・計上範囲を固定する |
| 一時ポート | 多数の新規originで許可待ちになる | 開始前に必要URLを列挙、承認済み固定gatewayへ設計する |
| timeout | 遅いページを短い上限で落として速い値だけ残す | 上限を事前定義し、失敗も保存する |
| Playwright route | 外部遮断のroute設定でキャッシュ測定が壊れる | キャッシュを維持できる配信・ネットワーク制御を使う |
| TTFB | 遅延設定より短いTTFBから制限無効と結論する | 0/150/300/1000/3000 msで各タイミング段階を校正する |
| 校正assert | 一方向の誤差判定で遅延が大きすぎても合格する | 差分の上下限と基準条件の対応を確かめる |
| loadだけ | load完了を動画や表紙の完成と呼ぶ | コンテンツ固有のreadyと描画を記録する |
| LCP条件 | 背景タブ・観測途中のLCPを他条件と比較する | visibility・観測終了・入力の有無を保存する |
| 遅延画像白抜け | HTTPとnaturalWidthだけで画像を正常判定 | スクリーンショット、表示領域、操作後の描画を確認 |
| JS一括defer | 外部JSが必要なinline処理を先に走らせる | 依存図を作り、元の順序を壊さない |
| lazy一括 | ロゴや先頭スライドも後回しになる | 最初に必要な画像と画面外を分ける |
| CPUの推測 | DOM要素が多いので仮想化を即採用する | CPUプロファイルと業務要件から判断する |
| カタログ頁 | 見開きの正規化を不具合と判定する | beforeの仕様を観測し試験の期待値を直す |
| カタログ版 | 外側の版だけで内部XMLの時刻URLを見落とす | 内側の要求と冊子別生成設定を確認する |
| カタログ移植 | ローカル互換パッチを本番差分に混ぜる | 再現用・性能用の差分を別に管理する |
| 動画SSIM | 容量とSSIMから表示時間を予測して確定する | 同じ条件のブラウザー試験と人による画質確認を行う |
| 部分動画 | 観測終了までの転送量をMP4全容量と比べる | 部分転送、開始、全編再生を分ける |
| PHP不足 | 公開HTMLからPHP/DBまで復元できたと扱う | ソース範囲と仮データ・代替関数を明記する |
| lintのみ | 全件構文合格をPHP互換合格にする | 型・空値の実行試験とWP統合を追加する |
| テスト終了値 | 失敗を出しながら終了0になる | 故意の失敗でテストハーネスを検証する |
| 不自然な呼出し | footerだけ実行してWPの警告を実装不具合にする | 実際の呼出し順で再現し、警告を隠さない |
| 版の混在 | 実装前の報告を最終状態として使う | 各資料に版・日時・後継記録を付ける |
| レビューの盲信 | AIの仮説を証拠なしに報告へ採用する | 校正・再現・独立再集計で反証する |
| 資料の手編集 | Wordだけ直してJSON・manifestが旧版になる | 生成元から作り直し、数値・SHA・ページを検査 |
| 重複フォルダー | 更新日時だけで最新と判断し削除 | パス・SHA・片側ファイル・Unicode名を照合し保全 |
| 手動ビューアー | 通常URLも低速になると誤解する | 低速Chromiumを映す画面であると明示する |
| 同じタブで再アクセス | フラグメント移動を新規測定とする | 同じcontextの新pageでナビゲーションを起こす |
| クリック座標 | フォーカス時の自動スクロールで座標がずれる | preventScrollや表示倍率を含めて操作回帰を確認 |
| 測定競合 | 手動閲覧と本試験を同時に回す | 排他制御・自動停止・実行中状態を持たせる |
| 無操作タイムアウト | health pollingが操作時刻を更新し終了しない | ヘルスチェックと操作ハートビートを分離する |
| 秘密の再配布 | サイト一式をそのまま顧客・AI・ZIPへ渡す | 配布許可リストと値を表示しない検査を使う |
