# 次の案件で使う空テンプレート

このフォルダーを新しい案件へコピーし、角括弧の記入欄を埋める。未確認事項は未確認のまま残す。他案件の顧客名・ポート・数値をそのまま流用しない。

| 順番 | テンプレート | 用途 |
| --- | --- | --- |
| 1 | [初動質問票](01_intake.md) | 対象・権限・素材・担当をそろえる |
| 2 | [AIへの開始指示](02_ai_start.md) | 目的と操作範囲を固定する |
| 3 | [範囲・課題台帳](03_scope_issue.md) | 今回やる/やらない/別途見積、状態を管理 |
| 4 | [測定計画](04_measurement_plan.md) | 回線・キャッシュ・指標・母数を先に決める |
| 5 | [試験チェック表](05_test_matrix.md) | 機能・画面・性能の合格条件を残す |
| 6 | [ベンダーへの依頼](06_vendor_request.md) | 必要資料・配信設定・窓口を確認 |
| 7 | [進捗報告](07_progress_report.md) | 完了・実測・未測定・待ちを分ける |
| 8 | [本番反映・切戻し](08_release.md) | 適用と復旧の依存関係を管理 |
| 9 | [引継ぎ](09_handoff.md) | 次のAI/担当者が誤った版で再開しない |
| 10 | [秘密情報の検出通知](10_security_notice.md) | 値を含めず所有者に対応を依頼 |

通知・依頼のテンプレートを作ることは送信の許可ではない。外部へ送る際は案件の実施範囲と宛先を確認する。
