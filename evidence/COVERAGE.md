# 収録範囲

| 内容 | 収録方法 |
| --- | --- |
| 調査から報告・保守までの作業手順 | 手順書 |
| PHP・配信・画像・動画・カタログの論点 | 一般化したチェック一覧 |
| キャッシュや計測の落とし穴 | 症状・切り分け・対処 |
| AIへの指示・レビュー・引継ぎ | 手順と空テンプレート |
| 速度比較 | 計画と架空の報告例 |
| ベンダー・権限・費用・保守 | 確認事項と役割のひな形 |
| 実案件のファイル一覧・測定表・出典台帳 | 匿名化のため非収録 |

数値例や汎用の確認項目数は、この匿名資料の構成を表すもので、実案件の規模や実績を示さない。原コード、DB、認証値、実結果JSON、顧客サイト画像・動画は収録していない。
